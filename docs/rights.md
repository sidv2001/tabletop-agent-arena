# Game-content and asset rights

The repository's [MIT license](../LICENSE) covers its original Python code,
rules wording, documentation, and hand-authored SVG/HTML. Tic-tac-toe uses
traditional mechanics with newly written descriptions. Edgepaths-5's
five-by-five orthogonal connection rules, wording, and board illustration
were authored for this starter. No external card text, rulebook passage,
illustration, or proprietary dataset is bundled.

For each future game pack, record **separate** provenance for engine code,
rules text, card or piece data, visual/audio assets, and names or marks. A
permissive software license on an adapter does not license every depicted
game's writing or art. Include the exact license and attribution for any
third-party material permitted for redistribution; keep notices with that
pack. If permission or provenance is uncertain, leave the material out and
write independent descriptions and artwork instead. Mechanics may inspire an
original implementation; copying a commercial rulebook or card catalog is a
different question.

Magic: The Gathering, Catan, and Terraforming Mars are interests for future
research, **not** sources for card text, illustrations, complete rulebooks,
or scraped decks. Any adapter for an existing game must also check branding
and distribution rights independently. The
[U.S. Copyright Office](https://www.copyright.gov/register/tx-games.html)
explains the distinction between game ideas/methods and protected expression;
this policy is a practical publishing boundary, not legal advice.

The first preview is self-contained: no remote images, fonts, scripts, or
licensed game components. New packs should add rights notes and tests for
their own observations, legal moves, terminal rules, and any private data
*before* publication.
